Rejects an inner packet too large to fit in one maximum-size UDP payload. Called in both directions by run_one_exchange before transport or injection.

Moves one IPv4 packet from TUN to UDP and one reply from UDP back to TUN. Called by main for the tun-udp-one learning command on each peer.
