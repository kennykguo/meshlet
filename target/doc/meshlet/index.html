Crate meshlet

Expand description

Meshlet command-line entry point and the introductory socket/latency demos.

main owns argument defaults and dispatch only. Later-stage mechanisms live in their named modules so a command can be followed directly to its code.

Modules§

coordinator 🔒
UDP control-plane registration, endpoint lookup, and route advertisement.
firewall 🔒
A pure userspace model of stateful firewall reply tracking.
handshake 🔒
A minimal authenticated, one-round-trip UDP handshake.
identity 🔒
Long-term node identities, public-key authorization files, and hex encoding.
relay 🔒
A one-client UDP relay that forwards opaque datagrams.
routing 🔒
IPv4 prefix parsing and the coordinator’s expiring route-advertisement table.
secure_packet 🔒
The encrypted data packet used after a successful peer handshake.
tun 🔒
Carry one IPv4 packet in each direction between a Linux TUN device and UDP.

Functions§

firewall_demo 🔒
Walks through allowed, denied, protocol-mismatched, and expired firewall flows. Called by main for the firewall-demo learning command.
main 🔒
Parses the first command-line argument and dispatches to one mechanism entry point. Called by the operating system when the meshlet executable starts.
percentile 🔒
Selects a nearest-rank percentile from an already sorted duration slice. Called by udp_rtt_client and its nearest-rank unit test.
print_latency 🔒
Prints one duration in microseconds under a supplied label. Called by udp_rtt_client for its min, p50, p99, and max summary.
print_usage 🔒
Prints every accepted command and its positional arguments. Called by main when no command or an unknown command is supplied.
tcp_client 🔒
Sends a fixed TCP message and reads the echoed stream until the server closes it. Called by main for the tcp-client learning command.
tcp_server 🔒
Accepts one TCP connection, reads once, and echoes the bytes before closing. Called by main for the tcp-server learning command.
udp_bench_server 🔒
Echoes UDP datagrams continuously without per-packet output. Called by main for udp-bench-server as the peer for udp_rtt_client.
udp_client 🔒
Sends one UDP datagram and waits for one echo response. Called by main for the udp-client learning command.
udp_rtt_client 🔒
Measures stop-and-wait UDP round-trip times and reports their distribution. Called by main for udp-rtt-client; it expects udp_bench_server as its peer.
udp_server 🔒
Receives one UDP datagram and echoes it to the source endpoint. Called by main for the udp-server learning command.
verdict 🔒
Converts a firewall decision into its short display label. Called only by firewall_demo when printing each modeled decision.
